# Real Estate Investment Advisor

A Machine Learning based Real Estate Investment Advisor that analyzes property data, evaluates investment suitability, predicts future property value, and provides interactive market insights.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- MLflow
- Streamlit
- Plotly

## Project Features
- Property investment classification
- 5-year property value estimation
- Real estate market analysis
- Interactive dashboard
