# 💄 SUGAR Cosmetics – Instagram Performance Analytics

## 📌 Project Overview
This project analyzes SUGAR Cosmetics' Instagram performance using Power BI. The dashboard provides insights into audience engagement, post performance, campaign reach, and monthly trends to understand social media effectiveness.

## 🎯 Objectives
- Analyze Instagram engagement and audience interactions.
- Identify top-performing hashtags and post types.
- Track monthly trends in reach, impressions, likes, and comments.
- Evaluate campaign performance and audience growth.
- Generate insights to support data-driven social media decisions.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Data Cleaning and Transformation
- Data Visualization
- Social Media Analytics

## 📊 Key Analysis
- Engagement by source
- Follows by post type
- Likes, comments, shares, and saves
- Monthly reach and impressions
- Campaign performance
- Profile visits and follower growth
- Hashtag performance

## 🔍 Key Insights
- **Top hashtag by likes:** #MakeupGoals
- **Campaign type with the highest impressions:** Tutorial
- **Highest monthly reach:** August
- **Highest monthly impressions:** August
- **Highest monthly likes:** January
- **Highest monthly comments:** June

The dashboard highlights content performance patterns, audience engagement, and campaign effectiveness. These insights can help improve content planning and support data-driven social media marketing strategies.
