# Stock Market Analysis

## Project Overview
This project analyzes historical stock market data using SQL to identify trends, calculate moving averages, and generate BUY/SELL/HOLD signals.

## Tools & Technologies
- SQL
- MySQL
- Data Analysis

## Project Files
- Stock_Market_Analysis.sql — Database creation and analysis queries
- Stock_Market_Analysis_Insights_Report.pdf — Analysis findings and insights

## Key Objectives
- Analyze stock price trends across six companies
- Calculate moving averages
- Generate BUY/SELL/HOLD signals
- Summarize findings for data-driven decisions
