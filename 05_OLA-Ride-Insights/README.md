# 🚖 OLA Ride Insights – Data Analytics Project

## 📌 Project Overview

OLA Ride Insights is an end-to-end Data Analytics project focused on analysing ride-booking data for July 2024.

The project aims to understand business performance by analysing ride bookings, revenue, vehicle performance, cancellations, and customer and driver ratings.

The analysis transforms raw booking data into meaningful insights using Python, SQL Server, Power BI, and Streamlit.

## 🎯 Project Objectives

- Analyse overall ride-booking performance.
- Identify successful and cancelled bookings.
- Evaluate revenue and payment methods.
- Compare performance across different vehicle types.
- Analyse incomplete rides and cancellation patterns.
- Understand customer and driver ratings.
- Present insights through interactive dashboards.

## 📂 Dataset Information

- **Total Records:** 103,024
- **Total Columns:** 20
- **Time Period:** July 2024

The dataset includes booking status, vehicle type, pickup and drop locations, booking value, payment method, ride distance, and customer and driver ratings.

## 🛠️ Tools & Technologies

- **Python:** Data cleaning and preprocessing
- **Pandas:** Data manipulation and analysis
- **SQL Server:** Database management and SQL queries
- **Power BI:** Interactive business dashboards
- **Streamlit:** Web-based analytics application
- **Plotly:** Interactive data visualisations

## 🔍 Project Workflow

1. **Data Understanding:** Explored the dataset and understood its structure.
2. **Data Cleaning:** Used Python and Pandas to inspect and clean the data.
3. **SQL Analysis:** Created a database and performed business analysis using SQL queries.
4. **Power BI Dashboard:** Developed five interactive analytical dashboard pages.
5. **Streamlit Application:** Built and deployed a web-based analytics dashboard.

## 📊 Power BI Dashboard Pages

The Power BI dashboard consists of five analytical pages:

1. **Overall Ride Analysis:** Total bookings, successful bookings, revenue, and booking status distribution.
2. **Vehicle Analysis:** Vehicle-wise booking value and ride-distance comparison.
3. **Revenue Analysis:** Revenue trends, payment methods, and key financial metrics.
4. **Cancellation Analysis:** Customer and driver cancellations, incomplete rides, and vehicle-wise cancellation patterns.
5. **Ratings Analysis:** Average driver and customer ratings across vehicle categories.

## 💡 Key Business Insights

- Total bookings recorded: **103,024**
- Successful bookings: **63,967**
- Customer cancellations: **10,499**
- Driver cancellations: **18,434**
- Driver-side cancellations were higher than customer-side cancellations.

These insights help identify areas for further investigation and potential operational improvements.
